# 福建 5 天 4 夜手机交互地图

深圳出发，2026 年国庆暂按 10 月 2 日出发、10 月 6 日返程，路线为厦门 2 晚 + 泉州蟳埔 1 晚 + 石狮海岸 1 晚。

## 页面内容

- 手机端 Leaflet 交互地图
- 第 1 天：深圳北 → 厦门北 → 沙坡尾 → 白城沙滩 → 中山路
- 第 2 天：厦鼓码头 → 鼓浪屿 → 龙头路 → 返回厦门
- 第 3 天：厦门北 → 泉州站 → 蟳埔村簪花 → 蚵壳厝和渔港 → 泉州东海/蟳埔附近住宿
- 第 4 天：泉州 → 洛伽寺 → 红塔湾 → 东城灯塔公园 → 小威海 → 石狮市区住宿
- 第 5 天：石狮市区 → 泉州站 → 深圳北，避开 10 月 7 日返程高峰
- 高铁与飞机的参考比较；厦门北→泉州站的短途动车衔接
- 蟳埔村簪花预留半天，现场确认妆造、服装、摄影和加片价格
- 石狮约 20 公里海岸线的打车/包车顺路安排
- 小红书、大众点评按钮：普通浏览器优先打开 App，内置 WebView 使用网页搜索
- 高德、Apple Maps、Google Maps 导航入口

## 说明

车票、船票、酒店价格会随国庆开售和实时库存变化。页面里的车票金额是当前参考区间，实际购买前要在 12306、厦门轮渡官方渠道和携程重新确认。洛伽寺和海边点还要根据当天海况、天气和现场管理调整停留时间。
